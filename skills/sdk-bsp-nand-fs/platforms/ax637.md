# AX637/AX637R 平台事实与资料路由

## 平台范围

- 适用 `AX637`/`AX637R` SDK；工作区识别优先使用 `build/platforms/axera/ax637*_demo_only_nand/`、`build/platforms/axera/ax637*_demo_only_emmc/` 和 `SafetyIsland/rt-thread/bsp/m57/configs_ax637*`。
- 当前 checkout 中 AX637/AX637R 的 NAND 项目是 Linux 主域 + Safety/RTOS 启动链，不按 QNX `ax_mtd`/ETFS 文件系统处理。
- 不因存在 M57 共用代码就把 M57 的分区、Flash 参数或日志路径套到 AX637。

## 源码与配置入口

- 平台配置与分区：`build/platforms/axera/ax637_demo_only_nand/`、`ax637r_demo_only_nand/`、对应 `partitions*.json`。
- U-Boot：`boot/uboot/u-boot-2022.10/arch/arm/dts/ax637*-demo-only-nand.dts`、对应 `configs/*-demo-only-nand_defconfig` 和 `board/axera/common/m57/common.c`。
- Linux：`kernel/linux/linux-6.1.83/arch/arm64/boot/dts/axera/ax637*-demo-only-nand.dts`、`kernel/linux/linux-6.1.83/drivers/mtd/nand/spi/`。
- Safety/RTOS 启动链：`SafetyIsland/sbl/`、`SafetyIsland/rt-thread/bsp/m57/configs_ax637*`；这些是启动链/Flash 适配证据，不是 QNX 文件系统入口。
- Boot/打包与文件系统工具：`build/scripts/`、`tools/mk*fs/`。

## 需要按目标确认

至少收集 board/`PLAT`、SDK revision、启动介质、Flash ID/geometry、完整串口日志、Linux `dmesg`/`/proc/mtd`/`/dev/link/*`、分区 JSON、生成包和复现边界。具体 NAND 型号、AB/non-AB、分区、DTS、Kconfig、OTA/FDL 包和运行时布局不能从共性文档推断。
