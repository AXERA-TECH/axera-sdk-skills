# M57 平台事实与资料路由

## 平台范围

- 适用 `M57` SDK；工作区识别优先使用 `SafetyIsland/mcal` 和 `build/platforms/axera/demo*/partitions*.json`。
- Linux 与 QNX 共用本 Skill，具体设备层、命令、日志入口和文件系统语义必须按环境区分。
- `demo_nor_nand`、`demo_only_nand` 等配置只能作为待核对目标，不能在未确认 `PLAT` 和启动介质时直接套用。

## 源码与配置入口

- Linux：`kernel/linux/`、`kernel/osdrv/`、`build/platforms/axera/`、`build/scripts/`。
- QNX/Safety：`SafetyIsland/sbl/`、`SafetyIsland/mcal/` 及对应构建配置。
- 文件系统工具：`tools/mk*fs/`；Boot/打包：`boot/uboot/`、`build/scripts/`。

## 证据要求

至少收集 SDK revision、实际 `PLAT`、Flash ID/geometry、完整串口日志、Linux `dmesg`/`/proc/mtd` 或 QNX `slog`/设备与挂载信息、配置与镜像包版本。缺失证据时只输出待验证假设；文档中的示例节点、参数和频率不能直接视为目标默认值。
