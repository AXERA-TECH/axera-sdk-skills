```text
结论等级：已确认 / 高可信待验证 / 信息不足
故障阶段：ROM/BL1/SPL-DDR/存储加载/OP-TEE或U-Boot/Linux/运行时/未知
结论：<一句话，不超过当前证据范围>
依据：
- 日志：<原文片段及顺序>
- 代码：<文件:行号或函数>
- 环境：<芯片、板型、介质、镜像版本>
机制：<仅解释被依据支持的因果关系>
客户可验证：

2. <预期结果及其含义>

```

## 常见日志的最小响应

| 现象 | 可直接回答的范围 | 仍需补充 |
|---|---|---|
| `ddr init fail` | SPL 已进入 DDR 初始化失败路径 | DDR 类型、training 前后完整日志；转 DDR skill |
| `flash:<name> init failed` | 存储 loader 初始化返回失败 | 介质、芯片模式、供电/时钟、同镜像稳定介质 |
| `<image> image load failed` | 指定镜像读取/校验失败 | 镜像名、分区/偏移、原始读校验、镜像哈希 |
| `<image> post-load failed` | 镜像已读到但后处理失败 | DTB/bootargs 宏、地址布局、完整上下文 |
| `kernel boot failed!` | 已触发 Linux 启动失败计数并回退 | 前一次启动日志、rcS 清除标志、复位原因 |
| 无任何 BL1 输出 | 不能判断是否执行 | UART 参数、DEBUG 宏、镜像/启动模式、上电波形 |
