# AX637 / AX637R OTA 平台事实

## 继承与环境

通过路由继承公共 OTA 流程；本文件覆盖平台差异。已收集依据仅覆盖 AX637/AX637R Linux。QNX handler、ETFS、QNX 节点及 M57 历史个案不属于本平台事实。

## 源码位置

- 目标配置：`build/platforms/axera/<PLAT>/config.mk`；如用户明确指定 `ax637_demo_only_nand`，才读取/修改对应目标，不能据此默认 PLAT。
- 包生成：`build/scripts/ota/swu_make.sh`、`build/scripts/ota/config/*/sw-description-source`；实际 config 名称从构建选择逻辑追踪。
- 手册记录 Linux overlay：`rootfs/buildroot-2024.02.2/board/axera/m57/fs-overlay/usr/lib/swupdate/`。路径中的 m57 是该版手册记录，不是路由检测依据；当前 SDK 路径需核对。
- 实际平台部署由 Buildroot package、init scripts 和 overlay 决定，读取最终 rootfs 的有效文件。

## 核心知识

本平台使用说明 §11 支持 A/B、SWU 签名/hash/版本/分区校验、差分、首次启动验证和失败回退。复用公共分层与成功判据；详细 BCB state 字段必须对照本版脚本核实，不能仅凭架构继承视为已验证。

## 构建配置与验证

Linux 手册顺序为 `make -C build PLAT=<已确认目标> all install axp` 后执行 `make -C build PLAT=<已确认目标> swu`，产物位于 `build/out/<PLAT>/images/`。先检查实际 Makefile、工具链与 AB 配置。

A/B 两块分别描述升级目标，修改需对称。文档明确可写、UBI、ext4 分区不可差分（包括只读场景），应采用完整包。差分需同时核对 `OLD_AXP`、`rdiffbase` 和板端对应 artifact。

本版手册首次测试入口为 `custom_test.sh`，退出 0 表示通过；最终以 ota_check 实际调用者为准。`UPDATE_MODE`、`SWU_PATH`、`DEBUG_LEVEL` 位于最终部署的 `conf.d/10-mongoose-args`；本地升级入口为 `/etc/init.d/S80swupdate start`，web 入口为板端 `:8080`。这些命令会触发升级，仅在授权实际升级时执行。

## 信息收集清单

板型、SDK/OS、明确的 PLAT/介质/AB、包 hash、当前/目标版本、布局及语义 link；SWUpdate 与重启日志、BCB、AB metadata、实际槽、最终验证脚本和返回值。Linux 存储证据按实际介质取 `/proc/mtd` 或 `/proc/ax_proc/emmc_partinfo`，不采 QNX 命令作为本平台证据。

## 常见问题排查表

以下为本平台使用说明导出的排查项，均须核对目标 SDK，不引用其他产品的历史个案 作为已证实根因。

| 现象 | 可能根因 | 操作 | 参考 |
|---|---|---|---|
| swu 无法生成 | AXP 输入缺失/混用 | 核对 all/install/axp 产物集合 | A §11.1.2 |
| A→B 成功，B→A 异常 | 两块描述不对称 | 核对两侧 image/device/type | A §11.3.1 |
| 分区校验失败 | 包与板端布局不同 | 对照 layout 和实际 link，重制匹配包 | A §11.1 |
| 差分失败 | OLD_AXP 或 rdiffbase 不匹配 | 对照旧 artifact；不确定则用全量 | A §11.3.6 |
| ext4/UBI 差分不可靠 | 文件系统改变原始数据 | 使用完整包 | A §11.3.6 |
| 回读校验失败 | 写入数据或介质错误 | 对照包 hash、回读日志和底层错误 | A §11.3.4 |
| 写入成功但重启失败 | 目标启动/功能验证失败 | 联查实际槽、启动日志、验证与 fallback | A §11.1.1、11.3.10 |
| 同步耗时长 | 成功后全量复制 | 核对 SYNC、分阶段耗时和对侧容量 | A §11.3.7 |
| 失败后发生内容复制 | 默认 AB 内容恢复 | 核对 RESUME，不把它等同网络续传 | A §11.3.8 |
| 自定义测试未运行 | overlay 或调用路径不匹配 | 追踪最终 custom_test.sh 和调用者 | A §11.3.10 |
| 本地/web 模式错误 | 最终配置与预期不同 | 核对 UPDATE_MODE、SWU_PATH 和服务参数 | A §11.3.14、11.4 |
| SWU 验签失败 | 签名与板端公钥/包不匹配 | 核对信任链；失败停止写入 | A §11.5.2 |

## 限制与约束

继承仅复用公共机制，不代表已做 AX637 实板验证。OS 专属实现和历史缺陷不自动继承。手册中的路径与工具版本是定位线索，不能绕过目标 SDK 检查。
