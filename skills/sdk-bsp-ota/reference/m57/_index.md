## 按环境加载

- Linux 实现、部署或首次验证问题优先加载 L；Q 可以补充共用框架，不因文件名含 QNX 而排除整篇内容。
- QNX 实现问题优先加载 Q；L 的 rootfs 覆盖链只应用于对应 Linux 构建。
- L/Q 的公共规则由平台事实层统一维护；两份技术文档保留各自路径与部署差异，不作为两套独立 skill。
- `axera_test.lua/axera_test.sh` 在 L 和 Q 中都有记录，不能用它们区分 OS。M 的 `custom_test.sh` 是文档/版本差异，应追踪最终调用链。
- 本技能不分发 SDK 源码；涉及 AB 选择算法和存储驱动时，在目标 SDK 核对实现。
