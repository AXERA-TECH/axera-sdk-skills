# Platform: m57

Axera M57 架构层 SDK 编译构建、组件独立编译与 AXP 打包规范。

## 平台说明与工程命名规则

M57 架构工程命名格式为：`BOARDNAME_FLASHTYPE`。
- **BOARDNAME**：`demo`、`evb`
- **FLASHTYPE**：
  - `nor_emmc`：Safety Nor + Main eMMC 启动设备组合
  - `nor_nand`：Safety Nor + Main Nand 启动设备组合
  - `only_nand`：仅 Main Nand 可用，Safety 与 Main 镜像均存放于 Main Nand
  - `only_emmc`：仅 Main eMMC 可用，Safety 与 Main 镜像均存放于 Main eMMC

典型工程示例：`demo_nor_nand`、`demo_nor_emmc`、`demo_only_nand`、`demo_only_emmc`。

## 全版本编译与 AXP 打包流程

全量构建前提：主机环境已通过 `sdk-bsp-sdk-environment` 就绪（工具链已安装且环境变量配置完成，`sdk_unpack.sh` 已完成解包打补丁）。

1. **查看工程列表**：
   在 SDK `build/` 目录下执行：
   ```sh
   make plist
   ```
   核对输出中实际存在的平台名称。

2. **执行全版本构建与打包**：
   ```sh
   cd Axera_M57_SDK_Vx.x.x/build
   make PLAT=demo_nor_nand clean all install axp
   ```
   - `clean`：清除历史构建产物（增量构建时可省略）；
   - `all`：编译全部 SDK 组件（ATF、OP-TEE、U-Boot、Linux Kernel、rootfs、msp 等）；
   - `install`：安装归档镜像产物；
   - `axp`：调用打包工具生成供 AXDL 烧录的 `.axp` 压缩包。

3. **产物核验**：
   - 目录位置：`build/out/demo_nor_nand/`
   - 镜像子目录：`build/out/demo_nor_nand/images/`，核验包含 `fdl1`、`fdl2`、`u-boot`、`kernel` 等（`bl31`、`optee` 仅在对应 `SUPPORT_ATF`/`SUPPORT_OPTEE` 启用时存在）；
   - AXP 交付包：`build/out/axera_demo_nor_nand_<SDK_VERSION>_<timestamp>.axp`。

## 分立组件独立编译规范

对于日常驱动调试或快速迭代，可进入各组件子目录独立编译，产物自动归档至 `build/out/<PLAT>/`：

| 组件名称 | 源码/工作目录 | 独立编译命令 | 对应配置文件路径 / DTS | 核心输出产物 |
|---|---|---|---|---|
| **ATF** | `boot/atf` | `make PLAT=<PLAT> clean all install` | `boot/atf/` 内部平台配置 | `build/out/<PLAT>/images/bl31.img` |
| **OP-TEE** | `boot/optee` | `make PLAT=<PLAT> clean all install` | 可选，受 `build/platforms/<vendor>/<PLAT>/config.mk` 控制 | `build/out/<PLAT>/images/optee.img` |
| **U-Boot** | `boot/uboot` | `make PLAT=<PLAT> clean all install` | `boot/uboot/u-boot-2022.10/configs/m57-<PLAT>_defconfig` | `build/out/<PLAT>/images/u-boot.img` |
| **Linux Kernel** | `kernel/linux` | `make PLAT=<PLAT> clean all install` | `kernel/linux/linux-6.1.83/arch/arm64/configs/m57-tiny_defconfig`<br>DTS: `arch/arm64/boot/dts/axera/` | `build/out/<PLAT>/images/kernel.img` |
| **Rootfs** | `rootfs` | `make PLAT=<PLAT> clean all install` | 依赖 `rootfs/prebuilt/` 预编文件与 `build/scripts/package_rootfs.sh` | `build/out/<PLAT>/images/rootfs.img` |

## 关键构建选项控制

1. **OP-TEE 裁剪/启用**：
   在 `build/platforms/<vendor>/<PLAT>/config.mk` 中配置：
   ```makefile
   SUPPORT_OPTEE := FALSE    # 选项值必须为 TRUE 或 FALSE
   ```
   若配置为 `FALSE`，构建系统不会编译 OP-TEE 源码，且 AXP 打包时不包含 `optee.img`。

2. **DTS 与 Defconfig 修改生效**：
   修改内核或 U-Boot 配置后，建议先在对应组件子目录执行 `clean all install` 验证单组件编译无误，再回到 `build` 目录执行 `make PLAT=<PLAT> axp` 重新打包。
