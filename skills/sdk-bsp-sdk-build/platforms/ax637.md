# Platform: ax637

AX637 / AX637R SDK 编译构建、组件独立编译与 AXP 打包规范。

## 平台说明与继承关系

AX637 / AX637R 基于 Axera M57 架构。在 Makefile 编译框架、参数约定（`clean all install axp`）、产物组织结构（`build/out/<PLAT>/`）及组件独立构建方式上完全承袭自 M57 规范。

本平台在 `routing.yaml` 中通过 `extends: m57` 继承 `platforms/m57.md` 的构建流程，但板级目标命名、U-Boot 版本基线及默认 Defconfig 与 M57 存在差异。

## AX637 与 M57 构建差异说明

- **板级工程命名**：
  - 格式为：`BOARDNAME_FLASHTYPE`
  - `BOARDNAME`：`ax637_demo`（安防领域）、`ax637r_demo`（边缘计算领域）
  - `FLASHTYPE`：`only_nand`、`only_emmc`
  - 实际平台目标：`ax637_demo_only_nand`、`ax637_demo_only_emmc`、`ax637r_demo_only_nand`、`ax637r_demo_only_emmc`
- **U-Boot 版本与配置**：
  - 与 M57 架构基线一致，AX637 同样采用 `u-boot-2022.10`；
  - 其配置文件位于 `boot/uboot/u-boot-2022.10/configs/ax637-<...>-defconfig`。
- **Linux Kernel 配置**：
  - Defconfig 文件名为 `ax637-tiny_defconfig`（位于 `kernel/linux/linux-6.1.83/arch/arm64/configs/`）。

## 全版本编译与 AXP 打包流程

1. **进入 build 目录核验平台支持**：
   ```sh
   cd Axera_AX637_SDK_Vx.x.x/build
   make plist
   ```
   确认目标平台列在支持清单中。

2. **全版本构建与 AXP 打包**：
   ```sh
   make PLAT=ax637_demo_only_nand clean all install axp
   ```
   构建完成后输出：
   - 镜像输出路径：`build/out/ax637_demo_only_nand/images/`（包含 `fdl1`, `fdl2`, `u-boot`, `kernel`, `rootfs` 等；仅当 `SUPPORT_ATF`/`SUPPORT_OPTEE` 启用时才包含 `bl31`, `optee`）；
   - AXP 打包文件：`build/out/axera_ax637_demo_only_nand_<SDK_VERSION>_<timestamp>.axp`。

## 分立组件独立编译规范

各分立组件支持在对应目录中以相同 `PLAT` 独立构建：

| 组件名称 | 源码/工作目录 | 独立编译命令 | 对应配置文件路径 / DTS | 核心输出产物 |
|---|---|---|---|---|
| **ATF** | `boot/atf` | `make PLAT=<PLAT> clean all install` | 架构内部配置 | `build/out/<PLAT>/bl31.img` |
| **OP-TEE** | `boot/optee` | `make PLAT=<PLAT> clean all install` | 可选，受 `build/platforms/<vendor>/<PLAT>/config.mk` 控制 | `build/out/<PLAT>/optee.img` |
| **U-Boot** | `boot/uboot` | `make PLAT=<PLAT> clean all install` | `boot/uboot/u-boot-2022.10/configs/ax637-demo-only-nand_defconfig` | `build/out/<PLAT>/images/u-boot.img` |
| **Linux Kernel** | `kernel/linux` | `make PLAT=<PLAT> clean all install` | `kernel/linux/linux-6.1.83/arch/arm64/configs/ax637-tiny_defconfig`<br>DTS: `arch/arm64/boot/dts/axera/` | `build/out/<PLAT>/images/kernel.img` |
| **Rootfs** | `rootfs` | `make PLAT=<PLAT> clean all install` | `rootfs/prebuilt/` 与 `build/scripts/package_rootfs.sh` | `build/out/<PLAT>/images/rootfs.img` |

---

## 构建选项配置

- **关闭 OP-TEE**：
  若工程不需要 OP-TEE，在 `build/platforms/<vendor>/<PLAT>/config.mk` 中设置：
  ```makefile
  SUPPORT_OPTEE := FALSE
  ```
  在 `build` 重新打包后确认无 `optee.img`。
