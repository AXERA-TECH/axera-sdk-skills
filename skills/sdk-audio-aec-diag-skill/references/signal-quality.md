# 音量、双讲与处理效果（Phase 3）

## 一、参考有信号但内容不对

分别播放远端语音、提示音和其他混音源，记录时刻，对照实际 ref 与已标明采集点的 mic。某路只进扬声器未进参考，检查该路取样/混音位置，按公开路由修正后复测所有播放组合。

ref 非零不证明取对流，远端停顿时静音也正常。低相关还需排除弱信号、噪声、削顶、频响差异、双讲、纯音多峰和搜索范围不足；固定反相本身不等于 AEC 故障。

若应用使用对外 `ax_ao_api.h` 的 `AX_AO_SendFrame` 混音，保存 `pstFrame/pstMixFrame` 对应素材、`f32MixWeight`、发送时刻和返回值。按《AX AUDIO API 文档》V1.7 §2.2，该接口用于非 Link 模式，混音权重 0–1，两帧位宽和声道数须相同，混音仅支持 16-bit。仅提示音有回声时逐路播放对照实际 ref；函数原型不能证明参考取样在混音前还是混音后。

## 二、采集、播放与大音量问题

大音量漏回声、破音或异常位置不清时，先按 [collection.md](collection.md) 固定素材、测量区间和产品条件。以下结合《AX 音频调试指南》§2.3、§2.10（封面 V0.1，修订历史含 2025/12/01 V0.2）的增益与逐点 Dump 方法安排对照；采集点和接口使用匹配版本的对外定义。

### 分阶段缩小异常范围

保存原故障录音与配置，再按现有证据选择一个实验。每轮写清“本阶段观测 → 支持的范围 → 下一步”，按需补相邻点：

| 阶段 | 控制条件与观测 | 判断与下一步 |
|---|---|---|
| 采集 | 本机停止发声，固定近端声源和位置，观察注明前置处理的 AEC 前 MIC | 此处已有非预期无声、异常噪声或失真时，先查采集与增益；正常则在原故障条件下继续查播放和耦合 |
| 播放 | 固定素材和目标音量，对照已确认的播放侧数字采集点与实际发声；需要时由硬件人员补 DAC/PA 测量或外部测量麦录音 | 数字数据已异常则向前查素材、混音和处理；数字正常而实际发声异常则查后续电气/电声级 |
| 回声耦合 | 远端单讲、近端不讲话，保留产品装配和播放条件，采集实际 ref 与 AEC 前 MIC | 对照缺失、削顶和音量变化，缩小参考支路或采集支路；两路有效且连续后再评价处理输出 |
| AEC 效果 | 核对实际配置、mic/ref/output 采集位置和时间关系，比较故障区间的输出 | 按第三节区分 AEC 与其他处理影响；修正后完成主流程规定的语音场景和原触发条件复测 |

测量麦用于观察实际发声，其录音不能替代 VQE_REF/Rin。需要时延或能量比较时，另满足 [delay.md](delay.md) 或第三节的前提；文件命名和同时发起录制不能证明采样同步。

调整处理开关或采集方式前按 [diagnosis.md](diagnosis.md) 核对调用阶段，变更后的材料另记轮次并恢复原值。相邻测点不足时，注明尚未验证的区间，保留具体器件或算法根因待查；单次正常不能排除其他音量、负载或产品条件的问题。

### 定位增益与首次失真

记录 codec 模拟/数字增益、ALC、`VqeVolume`、AGC，以及目标播放音量和最低近端拾音要求。在产品允许的声压范围内分档对照，按本板已确认的播放、参考和采集路径找最早观察到异常的位置：

| 已有证据 | 调整或补采方向 | 修正后的判据 |
|---|---|---|
| 播放侧数字数据已削顶 | 比较素材、混音及增益前后的可采集点，调整首次引入异常的一级；后级衰减不能恢复已经丢失的波形细节 | 该处波形恢复，且实际播放仍达到产品要求 |
| 播放侧数字正常，DAC/PA 或实际发声异常 | 由硬件人员按本板器件规格和测量方法区分对应级，再调整该级设置 | 对应测点和实际发声改善；只有数字录音时保留模拟级待确认 |
| 实际播放正常，实际 ref 或 AEC 前 MIC 削顶 | 分别检查参考与采集支路的前置增益；只改异常支路，ALC 状态按下节核对 | 该路失真减轻，弱近端语音、目标播放音量和 AEC 效果均满足要求 |
| mic/ref 未见相同异常，VQE 输出失真或语音受损 | 按第三节核对完整处理配置，补相邻公开采集点，单变量对照 | 输出恢复且近端保真通过；整体 VQE 前后差异仍不能单独归因 AEC |

最早观察到异常的点不一定是故障起点，缺少上游测量时保留待查。数字未满幅不能排除模拟失真，满幅也不单独证明器件故障；降低音量后改善但低于产品要求，只能作为定位线索。回声减小后仍需在原装配、目标播放音量及近端拾音条件下复测。

### 增益设置无效或关闭 ALC 后变小

以下依据《AX 音频调试指南》§2.3（封面 V0.1，修订历史含 2025/12/01 V0.2）。ALC 约定用于匹配板型的内置 codec RX；外置 codec 按其对外说明确认。

先用本版 `tinymix contents` 读取控件，记录目标声卡、控件名称和值；卡号选择按本版帮助，不能复制其他板的控制编号。

| 观察 | 判断与验证 |
|---|---|
| ALC 开启时手动调模拟/数字增益无效 | 该版 RX ALC 与手动增益互斥；ALC 应在录音前开启，使用期间不手动修改两级增益 |
| 关闭 ALC 后音量变小或重启后不一致 | ALC 使用期间会将两级增益设为 0 dB；关闭后需重新配置目标增益，再核对控件和录音 |
| 增大 `VqeVolume` 后削顶 | 该版范围 0–10，1 为不放大，0 为静音；它不能防止削顶，定位首次失真点后只调整对应一级 |

这些实验记录并恢复原值；降至静音或产品要求以下不能作为修复。增益变化后重新采集对照，旧录音不能证明新状态。

### 左右电平或频响不一致

应用已有 codec 控制时，可按对外 `ax_acodec_api.h` 补读以下状态，记录 `ACODEC_CARD`、方向、声道、返回值与有效输出：

| 核对目标 | 公开读回入口示例 | 如何判断 |
|---|---|---|
| RX/TX、左/右、模拟/数字增益 | `AX_ACODEC_GetRxLeftAnaGain`、`AX_ACODEC_GetRxRightDigGain`、`AX_ACODEC_GetTxLeftDigGain` 等对应 getter | 根据本板接线确认 MIC/REF 对应声道，比较切换或关闭 ALC 前后是否恢复到目标值 |
| EQ、HPF、LPF | `AX_ACODEC_RxEqGetAttr`、`AX_ACODEC_RxHpfGetAttr`、`AX_ACODEC_RxLpfGetAttr` 及对应 TX 接口 | 记录使能、采样率、频率和增益，与波形/频响变化对照 |
| 扩展 EQ | `AX_ACODEC_RxEqGetAttrEx`、`AX_ACODEC_TxEqGetAttrEx` | 仅使用该功能时补各段频点、Q 和类型，避免扩大无关采集 |

头文件未给出所有声卡支持情况、gain 单位映射和参数范围，不能据 `s32Gain` 统一换算 dB 或照抄控制编号。读回与录音共同用于判断；未满幅也不能排除前端失真。单变量对照后恢复原值。

## 三、双讲吞音或首字丢失

按主流程录制四种语音场景并标记谁在讲话，对照 VQE 输入、实际 ref、VQE 输出和最终发送流；有条件使用可重复的近端声源，验收以客户要求或认可的正常基线为准。各点含义见 [collection.md](collection.md)：Sin 已可能经过前置处理，Sou 包含本轮启用的 VQE 功能，不能把其变化全归给 AEC。

1. 先确认近端单讲采集和输出正常。
2. 双讲时逐段比较首字、持续语音、停顿后恢复和可懂度，找首个变差的处理点。
3. 记录下表中的有效处理配置和增益，调整时同时观察回声与近端保真。

按《AX AUDIO API 文档》V1.7（2026/07/13）§3、§5 及对外 `ax_audio_process.h` 核对以下参数；AEC 只解释当前活动分支，模式/初始化与版本支持先按 [diagnosis.md](diagnosis.md) 第一节确认：

| 参数 | 含义与动作 |
|---|---|
| FLOAT 的 `enSuppressionLevel`、FIXED 的 `eRoutingMode` | 都是对应模式的抑制设置；`eRoutingMode` 不能当作硬件路由或 layout。proc 的 `SupOrRouting` 随模式解释 |
| FLOAT 的 `stSuppressExCfg` | 记录 `bEnable/stSuppressExLevel`，level 为 0–2；增强等级更高可能同时增加近端语音损失，单变量对照时双讲和首字保真一并验收 |
| FLOAT 的 `enComfortNoiseLevel` | OFF=0、LEVEL_1=1；静音段低电平背景声先记录此项，输出非零不单独证明残余回声，开关也不能自证噪声来源 |
| `bExtFilterEnable` | 对外资料仅给出开关定义；没有依据时不推导最大补偿时延或房间推荐值 |
| `stNsCfg/stNsAdvCfg` | 分别记录使能和 `enAggressivenessLevel`，其定义列 0–5、注释默认 2；关闭普通 NS 不证明 NSAdv 也关闭。公开注释说明更强抑制会增加语音失真，需单变量对照 |
| `stAgcCfg` | 记录 `bAgcEnable/enAgcMode/s16TargetLevel/s16Gain`；target 范围 -31–0、注释默认 -3，gain 范围 0–90、注释默认 9。该版文档将 gain 定义为最大增益；实际值、字段含义及模式能力分开核对 |
| `stVadCfg` | 记录 `bVadEnable/u32VadLevel`，level 0–3、注释默认 2；首字或弱近端变化时对照，不能仅凭开关推断具体静音机制 |
| proc `Bypass` | 1 旁路 VOL_CTL、2 旁路整个 VQE、3 同时旁路两者；整体旁路差异不能独自定位 AEC |

表中范围用于匹配版本的合法性核对，不是通用调参推荐。注释默认不替代现场读数；完整配置缺项时标为待确认，不把缺失的 NSAdv 或其他开关当作关闭。

确需旁路对照时，保存原值，按匹配版本的 `echo Bypass [AiCardId] [AiDevId] [IntValue] > /proc/ax_proc/ai` 设置并核对状态，短时采集后恢复原值；这不是仅关闭 AEC 的命令。需要区分 VQE 中具体功能时，按 [diagnosis.md](diagnosis.md) 的合法设置阶段单独调整，保留其他配置。

双讲总能量包含近端语音，不能用 mic/output 能量差确诊吞音。单讲回声减小但双讲变差，整体效果仍未通过。

仅在远端单讲、同次录音、mic/output 同率同长且对齐、两点之间仅有 AEC 处理且为单位增益时，解释 `energy_reduction_proxy_db = 10 log10(Pmic/Pout)`。有 HPF、NS/NSAdv、AGC、VAD 等其他处理时不宣称 AEC 独立效果；舒适噪声状态另行注明，输出能量不全代表回声。这是能量衰减代理值，不是标准 ERLE；输出全零还需查静音与近端保真。

## 四、后级或声学条件变化

- **VQE 输出正常，发送流变差**：逐点比较后级动态增益、重复处理、编码和发送路由，定位首次变化；编码计数见 [delay.md](delay.md)，只有端到端录音时说明中间缺证据。
- **移动、遮挡、换壳、靠墙或音量变化后变差**：记录事件和恢复过程，固定其他条件重复；恢复时间不能单独证明 SDK 缺陷。
- **长混响、多扬声器或立体声独立内容**：简化到单路对照，核对公开支持的参考数量与使用条件；需要声学或算法能力确认时交接，不指定未经确认的内部参数。
