# AX615 VO 时序配置

> 本文档由《AX615 VO时序配置-v7-20260910》PDF 转换而来。
> 表内数值按 PDF 逐格转录，并用时序规则交叉校验：每一行均满足
> `u16Vact+u16Vbb+u16Vfb+u16Vpw = vts`、
> `u16Hact+u16Hbb+u16Hfb+u16Hpw = u32Pclk/fps/vts`，
> 且 `u32Pclk` 命中 {36000, 74250, 148500}（驱动 `disp_rx_clk` 仅接受这三种）之一。

## 时序计算规则

1. BT656 单沿（SDR）：默认 `bDlbClk=0`，`u8DelaySel=0`
2. BT656 双沿（DDR）：默认 `bDlbClk=1`，`u8DelaySel=3`
3. `u16Hact`：有效宽；`u16Vact`：有效高
4. `u16Vact + u16Vbb + u16Vfb + u16Vpw = vts`
5. `u16Hact + u16Hbb + u16Hfb + u16Hpw = u32Pclk / fps / vts`

## 字段说明

| 字段 | 含义 |
|---|---|
| 接口 | BT656 时钟边沿模式：SDR=单沿，DDR=双沿（对应左侧合并单元格） |
| bIop | 隔行/逐行输出标志（960H 隔行=0，其余=1） |
| u16Vact | 垂直有效行数（有效高） |
| u16Vbb | 垂直后肩（back porch） |
| u16Vfb | 垂直前肩（front porch） |
| u16Hact | 水平有效像素（有效宽） |
| u16Hbb | 水平后肩（back porch） |
| u16Hfb | 水平前肩（front porch） |
| u16Hpw | 水平同步脉宽 |
| u16Vpw | 垂直同步脉宽 |
| u32Pclk | 像素时钟，单位 kHz（148500 = 148.5 MHz） |
| bIdv / bIhs / bIvs | 数据/行同步/场同步有效电平标志 |
| bDlbClk | 双沿时钟使能（DDR=1，SDR=0） |
| u8DelaySel | 采样延时档位 |

## 备注

- 序号即 PDF 中的 `BT656` 列编号。
- `2880x1620` 系列：带 `_vts1728` 的行 vtotal=1728（对应 TX 输出 `HDCVI_2880x1620_*_V20`）；不带的行 vtotal=1650（对应非 V20）。
- SDR 行（3~6）的 `u16Hbb` 偏大属 TX 大 blanking 应用特性，已由公式校验（如 #3：`1280+2355+300+25=3960 = 74250000/25/750`）。
- 用标称 fps 反推 `u32Pclk` 时，个别行存在 <0.02% 的取整偏差（因 blanking 为整数、`u32Pclk` 取标称值）：`#15/#20/#21/#23/#24` 偏差 2~22 kHz；`#2` 的 `960x480@60i` 实为 59.94 Hz（NTSC）场频，`59.94×525×1144≈36000` kHz。这些均属正常取整，非数值错误。
- 数值来源为渲染逐格转录 + 时序公式反推双重校验；如与后续 PDF 版本不一致，以最新 PDF 为准。
