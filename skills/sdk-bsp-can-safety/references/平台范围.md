# 平台范围

以下范围来自用户确认。

## 支持

- M57 Linux 项目的 Safety 侧 AUTOSAR MCAL CAN。
- M57 QNX 项目的 Safety 侧 AUTOSAR MCAL CAN。

## 不支持

- AX637、AX637R：Safety 侧使用 RTT RTOS CAN 框架，不使用 AUTOSAR MCAL CAN。
- 主 CPU Linux SocketCAN。
- QNX 原生 CAN。
- SafetyIsland baremetal CAN。
- 其他非 M57 AUTOSAR MCAL CAN 软件栈。

主项目 OS 不能单独决定是否适用；必须确认 CAN ownership 和 Safety 侧使用的框架。
